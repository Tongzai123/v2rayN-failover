# v2rayN 7.20.4 故障自动转移版

本项目基于 [2dust/v2rayN](https://github.com/2dust/v2rayN) 的 `7.20.4` 版本二次开发，保留原版对 [Xray](https://github.com/XTLS/Xray-core)、[sing-box](https://github.com/SagerNet/sing-box) 以及其他核心的支持，并在原版基础上增加了故障转移和拖拽排序能力。

本项目不是 `2dust/v2rayN` 官方原版。如果需要官方版本、官方文档或官方问题反馈，请访问上游项目：

- 上游仓库：[2dust/v2rayN](https://github.com/2dust/v2rayN)
- 上游 Wiki：[v2rayN Wiki](https://github.com/2dust/v2rayN/wiki)

English documentation: [README.en.md](README.en.md)

## 主要增强功能

### 故障转移

新增转移分组、活动故障组和故障队列。你可以把多个普通节点加入故障队列，并按优先级排列。开启“故障转移”后，程序会按队列顺序使用这些节点作为转移候选。

故障队列中的节点会显示 `P1`、`P2` 等优先级标签，数字越小优先级越高。队列从上到下就是实际优先级顺序。

### 订阅分组拖拽排序

订阅分组标题支持拖拽排序。按住分组名称拖动到目标位置后松开，即可调整分组显示顺序。

### 节点列表拖拽排序

节点列表支持通过拖拽调整顺序。转移分组中的节点也可以拖拽调整故障队列优先级，并支持多选节点作为连续块一起移动。

## 故障转移使用方法

### 1. 创建转移分组

打开订阅分组设置，创建一个新的分组，并勾选“转移分组”开关。

创建完成后，转移分组的分组名称会以绿色标题显示，用于和普通分组区分。

### 2. 设置活动故障组

进入刚创建的转移分组，点击右上角的“当前组设置为活动故障组”。

设置成功后，该分组会成为当前用于故障转移的活动故障组。

### 3. 复制节点到转移分组

从普通分组中选择要参与故障转移的节点，可以使用以下任一方式复制到转移分组：

- 在普通分组中右键节点，选择复制到转移分组。
- 先复制节点，再切换到转移分组中粘贴。

### 4. 添加节点到故障队列

切换到转移分组，选中确定要参与故障转移的多个节点，然后执行以下任一操作：

- 按 `Enter`。
- 右键选择“添加到故障队列”。

添加后，节点会进入故障队列，并显示 `P1`、`P2` 等优先级标签。

### 5. 调整优先级

故障队列从上到下就是优先级顺序：

- 最上方节点优先级最高。
- 下方节点作为后续转移候选。
- 如果顺序不满意，可以直接拖动节点上下移动。
- 支持多选节点后一起拖动，多个节点会作为连续块移动。

### 6. 开启故障转移

确认活动故障组和故障队列都准备好后，点击下方的“故障转移”按钮，即可开启故障转移功能。

开启前请确认：

- 已经设置活动故障组。
- 故障队列中至少有一个有效节点。
- 队列顺序已经按你的优先级排列。

## 拖拽排序使用方法

### 节点拖拽

在节点列表中按住节点行并拖动，可以调整节点显示顺序。

在转移分组中，节点拖拽会同时影响故障队列优先级。拖动后的上方节点优先级更高，下方节点优先级更低。

### 多选节点拖拽

节点列表支持多选拖拽。选中多个节点后拖动，多个节点会保持原有相对顺序，并作为一个连续块移动到目标位置。

### 订阅分组拖拽

在主界面的订阅分组区域，按住真实订阅分组名称并拖动，可以调整分组顺序。虚拟的“全部”分组不参与拖拽排序。

## 使用提示

- 故障转移开启前，必须先创建转移分组、设置活动故障组，并把有效节点加入故障队列。
- 故障队列的优先级以界面从上到下的顺序为准。
- 如果节点拖拽排序受设置项影响，请在设置中启用相关拖拽排序选项，并按界面提示重启客户端。
- 本项目是基于 `v2rayN 7.20.4` 的二开版本，使用方式与官方原版大体一致，但故障转移和拖拽排序相关功能以本文档说明为准。
